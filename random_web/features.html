Features

Everything you need to watch live sports — nothing you don't.

Player

Auto-Format Detection

DASH (with ClearKey DRM), HLS, or direct MP4 — ZeroLive detects the format and plays it automatically.

Smart Server Fallback

When a stream fails, the player auto-switches to the next available server. No manual refresh needed.

Custom Progress Bar

Full-width scrubber with hover tooltip, smooth thumb, and no jitter. Scrub through the stream easily.

Speed Control

Adjust playback speed from 0.25x to 3x. Your preference persists per event.

Keyboard Shortcuts

Play/pause, mute, seek, fullscreen, volume — all accessible without a mouse.

Stream Info Overlay

Press I to see quality, format, and server name at a glance.

Sources

Multi-Source Aggregation

Events are merged from multiple upstream sources. The same match from different providers gives you fallback options.

M3U Export

Export any event as an M3U playlist. Open in VLC or any media player on any device.

Custom M3U Naming

Name any event and access it at your-ip/name.m3u. Fuzzy matching included.

Interface

11 Themes

Dark, light, amethyst, emerald, ruby, ocean, cyberpunk, sunset, nord, matrix, midnight. Glassmorphism cards with animated gradient orbs.

Skeleton Loading

Shimmer placeholders while data loads — no blank screens.

System Theme Detection

Auto-switches between dark and light based on your OS preference.

Responsive Design

Works on mobile, tablet, and desktop. Access from any device on your local network.

Technical

DRM Support

ClearKey DRM decryption for DASH streams. Handles encrypted manifests automatically.

TLS Fingerprint Impersonation

Uses curl-cffi to impersonate Chrome's TLS fingerprint. Bypasses anti-bot detection on stream sources.

Auto-Update

One-click updates from GitHub. Checks for new commits, downloads, and applies on next restart.
