Frequently Asked Questions

Everything you need to know about ZeroLive.

What is ZeroLive?+
ZeroLive is a free, open-source live sports streaming app for Windows. It acts as a lightweight local proxy on your PC that fetches live sports streams from multiple sources and serves them through a built-in web player. It supports football, cricket, basketball, tennis, Formula 1, UFC, WWE, rugby, and more.
Is ZeroLive really free?+
Yes. ZeroLive is 100% free, open source, and has no ads, no subscriptions, and no registration required. It streams from publicly available sources.
What sports can I watch?+
Football — Premier League, Champions League, La Liga, Serie A, Bundesliga, Ligue 1, MLS, World Cup, and more.
Cricket — IPL, BBL, PSL, CPL, ICC events, T20 World Cup, ODI series.
Basketball — NBA, EuroLeague.
Tennis — ATP, WTA, Grand Slams.
Formula 1 — All race weekends.
UFC / MMA — Fight nights and PPVs.
WWE — Raw, SmackDown, PPVs.
Rugby — Six Nations, World Cup.
Ice Hockey — NHL.
Availability depends on what's live at any given time.
How do I install ZeroLive?+
Windows Installer: Download the .exe from the download page, run it, pick your theme and install path, then click Launch.

Manual Install: Clone the repo, install Python 3.10+, run pip install -r requirements.txt, then python app.py 9090. Works on Windows, macOS, and Linux.
Do I need a VPN?+
It depends on your region and the stream source. Some streams may be geo-restricted. A VPN can help bypass these restrictions. ZeroLive does not provide a VPN — you'll need your own.
Why does the video buffer or fail to load?+
Source down — the upstream CDN may be temporarily unavailable. Try switching servers (click a different server button below the player).
Geo-restricted — some streams only work in certain countries. A VPN may help.
Network issues — try lowering the quality if your connection is slow.
ISP blocking — some ISPs block streaming CDNs. A VPN usually fixes this.
Can I watch on my phone or TV?+
Yes! Open http://<your-pc-ip>:9090 on any device connected to the same local network. You can also use the M3U URLs in VLC or any media player app on your phone or smart TV.
What's the difference between /watch and /lite?+
/watch/<slug> — Full custom player with 11 themes, custom SVG controls, speed control, keyboard shortcuts, and stream info overlay.

/lite/<slug> — Minimal player using native browser controls. Lighter, works everywhere.
How does auto-fallback work?+
When a stream fails (CDN error, timeout, etc.), the player automatically tries the next available server for that event. You'll see a brief spinner and then playback resumes on the new server. No manual intervention needed.
How do I update ZeroLive?+
Installer version: Open settings (gear icon) → Check for Updates → Apply.
Manual version: Run git pull origin master, then restart.
Does it work on Mac or Linux?+
Yes. The manual install works on any OS with Python 3.10+. The Windows installer is Windows-only, but you can run the same commands manually on macOS or Linux.
Is my data private?+
Yes. ZeroLive runs entirely on your local machine. No data is sent to any external server except the upstream stream sources. There's no telemetry, no analytics, no tracking.
What ports does it use?+
Default is 9090. You can change it via the PORT environment variable or by passing a port number: python app.py 8080.
