Installation Steps

  1. Click Download for Windows above to save ZeroLive_Installer.exe
  2. Run the installer — choose your theme and install path (default: C:\Zero_live)
  3. Click Launch or double-click Zero_live.bat on your desktop
  4. Your browser opens to http://127.0.0.1:9090 — start watching!

Manual Install (Any OS)

git clone https://github.com/rafu-milonmart/Zerolive.git cd Zerolive pip install -r requirements.txt python app.py 9090

Requires Python 3.10+. Works on Windows, macOS, and Linux.

Docker

docker build -t zerolive . docker run -p 9090:9090 zerolive
