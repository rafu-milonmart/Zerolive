About ZeroLive

A free, open-source live sports streaming proxy built for fans, by fans.

What is ZeroLive?

ZeroLive is a lightweight local proxy and streaming player that lets you watch live sports on your PC for free. It fetches stream metadata from multiple upstream sources, handles DRM decryption, and serves a polished web UI with a custom-built video player.

The key design principle: the server never touches the actual video data. Video segments are fetched directly by your browser from the CDN. This means ZeroLive uses virtually zero bandwidth while streaming, and can run on any machine — even a low-end laptop.

How It Works

ZeroLive acts as a bridge between stream sources and your browser:

  • Metadata fetch — The server fetches event listings and playback URLs from upstream APIs using TLS fingerprint impersonation (curl-cffi) to bypass anti-bot detection.
  • DRM decryption — For encrypted DASH streams, the server decrypts ClearKey DRM tokens and provides the decryption keys to the browser player.
  • HLS proxy — HLS manifests are proxied through the server (a few KB) with sub-playlist URLs rewritten. The browser fetches video segments directly from the CDN.

Technology Stack

  • Backend: Flask (Python) with curl-cffi for TLS impersonation and cryptography library for AES-GCM decryption
  • Server: Hypercorn (ASGI) with 4 workers, falls back to gunicorn gthread or Flask dev server
  • Player: hls.js, dash.js, and native HTML5 video
  • Frontend: Vanilla JavaScript, CSS custom properties with 11 theme variants, glassmorphism UI, SVG controls
  • Installer: PyQt6 GUI built with PyInstaller, deploys a portable Python runtime (~35 MB)

Supported Sources

ZeroLive aggregates streams from multiple sources:

  • Upstream API — Primary source with DASH/HLS streams and multiple server fallbacks
  • FanCode — Cricket and multi-sport streams (home network only)
  • TapMad — Cricket and sports streams via Akamai CDN

Privacy

ZeroLive runs entirely on your local machine. There is no telemetry, no analytics, no tracking, and no data sent to any external server except the stream sources themselves. Your viewing habits are your own.

Open Source

ZeroLive is completely open source under the MIT license. You can read the code, modify it, and distribute it however you like. Contributions are welcome.
